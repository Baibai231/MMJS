# 注册五方法新版算法：十万用户重测协议

用户授权：将新版算法接入第二板块现有比较对象，生成全量多方法比较，每组十万用户。

## 固定比较对象

1. 双向调整 v2（编辑成本感知、Pareto 筛选、组合搜索与条件攻击确认）。
2. Schechter 严格档，精确频次 oracle，阈值比例 $10^{-5}$。
3. Malone–Maher，包含拒绝提案的频次接受机制。
4. Segreti StructMNoHint 的统一模拟适配，固定结构黑名单。
5. GitHub 公开核心长度与字符要求。

新版替代主图中的旧版“我们的改进方案”；旧图及各开发版本结果保留，不作为新增独立方法混入主图。

## 数据与固定实现

五组共享新抽取的 100,000 个频次声明 occurrence、顺序、seed 11、十个注册批次和策略无关的用户提案序列。新 occurrence 排除此前工作区实验以及指定 C 盘实验的全部角色标识。开发、选择预览和确认预览角色沿用既有数据；相同口令字符串可以出现在不同角色，不能将 occurrence 不重叠解释为口令字符串不重叠或独立真人试验。

抽样种子为 202610130901。算法参数沿用已完成的 v2 单组实验，冻结配置后运行，不根据本次比较结果调参。新版首批从与 Segreti 完全相同的黑名单开始，必须核对目标结果、尝试次数及开发结果一致。

文献组基础规则为至少八字符、开发样本 top1000 常见口令屏蔽。GitHub 保留原图的公开核心配置，不复制站点完整规则，基础要求与文献组不同。Schechter、Malone–Maher 首批按基础规则启动，之后分别更新目标端在线机制；攻击训练端在独立开发角色上运行各自在线机制。

所有组继续提案直至接受，不设重试上限。每组独立记录实际完成量、额外提交次数、从最初口令到接受口令的 Levenshtein 距离、修改比例及超过三次额外提交的比例。距离测量只读取接受结果，不新增决策查询。

## 攻击与图表口径

最终攻击器 PCFG、OMEN 分别基于实际策略轨迹下的六万开发响应训练，不把目标明文加入训练。仅在完整训练计数哈希一致时复用既有攻击前缀。

主图延续原第二板块的相同总预算：1 千、1 万、10 万、100 万次，两攻击器各分配一半；同一账户联合命中只计一次，重复发射仍计预算。另导出单模型和每模型各给定预算的结果，明确区分两种联合口径。v2 控制器内部仍按原配置每模型 100 万次评价候选，不能将内部优化口径偷换为主图口径。

主图比较联合猜中比例和人均额外提交次数，补图比较修改距离、修改比例及重试尾部。所有结论绑定本次五组结果，不拼接旧分区数值。

## 核验与解释限制

结果交付前从私有计数及完整攻击前缀重新计数全部预算点；核对用户总数、尝试次数成本、逐批成本汇总、共同分区哈希、无待完成用户、无攻击失败。保存源码和配置哈希、分区来源、结果及图表清单。目标初始明文和接受明文只存私有目录，公开图表仅含聚合数据。

本次为冻结控制器在新 occurrence 流上的一次模拟复测；沿用数据来源与开发角色，不能称为独立数据集验证，也不报告跨随机种子误差条或“稳定优于所有方案”。结果论述保留实际出现的成本权衡及不利预算点。作者人工核验状态为待核验。
