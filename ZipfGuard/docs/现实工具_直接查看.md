# 已配置的本机可操作展示

在当前电脑，双击项目目录中的 **打开可操作展示.cmd**。它自动启动后台，打开专用浏览器的三个标签页：已登录的管理员控制台、用户浏览器助手、独立网站接入样例。无需手动解压扩展或填写安装邀请。

管理员页面可以查看已有受保护画像、制定注册政策、比较整改要求、查看账户任务和作业；用户页面可以进行本地检查、注册、私密登录和改密。已有7个合成账户及真实验收画像，显示的是实际后端数据。操作会真实改变本机账户、策略和预算。

用户助手自动尝试登录已有合成演示账户，口令只输入扩展。演示账户改密或注销后，下次无法自动登录时仍可直接注册自己的测试账户。两端仍采用独立来源和会话，不共享登录信息。

为方便直接查看，启动器在专用浏览器中使用保存在本机私有目录的演示软件通行密钥，经过正常WebAuthn验证进入管理员界面。该做法仅用于本机合成数据展示，不代表硬件认证器或正式管理员身份。普通管理台仍可按安装说明登记自己的设备通行密钥。

重复双击会切回已经打开的演示管理台。退出管理台后，演示启动器会重新认证；如需测试退出后的登录页面，请先关闭全部演示浏览器窗口，再用普通启动方式打开。关闭演示浏览器会结束展示助手，后台可用 **停止完整工具.ps1** 停止。

本机地址是 `https://localhost:8532`，用户入口属于浏览器扩展。请通过展示入口打开，以使用已经配置的本地测试证书和独立浏览器资料。它不改变系统证书或日常浏览器资料，并禁止解析外部域名。

出现启动问题时查看 `tool_runtime/ready-demo/status.json` 和 `ready-demo-launch.log`。此私有目录内含演示认证器，不能上传或分发。安装包不包含它。

移到另一台电脑时先按 [安装说明](现实工具_安装与使用.md) 完成安装。如需同样的自动展示，再安装 `requirements-viewer.txt` 并执行 `python -m playwright install chromium`。新机器生成自己的认证器和身份；自动登录合成用户依赖相应测试账户，不能复制私有运行目录。

本次验证范围见 [验收报告](现实工具_验收与边界.md)。完整画像在7账户上的等待约200秒；自动联合优化在缺少用户响应和成本证据时保持策略，手动快照阻断可实际执行。
