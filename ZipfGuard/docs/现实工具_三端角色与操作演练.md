# 三个页面分别做什么，怎样演练

真正使用工具的只有两类人：用户和管理员。第三个页面是接入工具的网站样例，相当于未来商城、论坛或校园网站自身的登录入口。

| 页面 | 你扮演谁 | 负责的事情 | 操作入口 |
| --- | --- | --- | --- |
| 用户口令助手 | 普通用户 | 选择口令、注册、私密登录、改密、查看本人任务、恢复账户 | 浏览器扩展，左侧有“口令助手”“注册账户”“我的任务” |
| 网站策略管理台 | 网站管理员 | 制定要求、查看受保护统计、安排整改、查看实际完成情况 | 管理台，左侧有“受保护画像”“注册动态策略”“账户与任务” |
| 独立业务网站接入样例 | 网站的访问者 | 让网站核验登录结果并建立自己的网站会话 | 页面标题“登录时，网站无需接触口令” |

用户的明文口令只填写在扩展里。管理员页面没有口令明细。接入网站得到三方认证证明，不得到明文口令。当前演示通过复制挑战和证明展示接入过程。

## 演练准备

双击 `打开可操作展示.cmd`，保留三个标签页。演示管理员已经登录；用户助手可能已登录 `integration-smoke`，本次另建账户，先在用户助手右上角退出。

本说明依据编写时的实际配置：基础要求8–64字符、无附加规则、策略版本5、累计隐私预算3、已分配整改人数2。若你已经改过设置，先记录当前版本，并在管理台“注册动态策略”设置最短8、最长64、取消附加规则，勾选确认并应用。以下步骤使用这套基础条件。

记下应用后的基础策略版本，结束时可回退到它。不同人口的画像重新发布需要等待，基础演练直接用已有快照即可。旧快照只代表发布时的人口，不会自动变成你注册后的最新画像。

本次使用新账户 `aaa-tour-1011`。如已存在，改为 `aaa-tour-1011b`，整套流程都使用同一个新标识。以下都是公开的合成演示口令，不要作为真实网站口令使用。

| 用途 | 测试值 | 长度 |
| --- | --- | ---: |
| 初始口令 | `M7!rQ2@x` | 8 |
| 新注册账户的合规口令 | `N8!sT4@vK6#p` | 12 |
| 能通过12字符基础要求、但不能通过15字符整改的口令 | `R9!uV5@wL8#q` | 12 |
| 完成整改后的口令 | `R9!uV5@wL8#qJ2!m` | 16 |
| 可选恢复后的口令 | `V6!nB3@rH9#tE4!k` | 16 |

## 1. 用户先选口令：本地拒绝与通过

在**用户助手 → 口令助手**：

1. 输入 `12345678`，点击“本地检查”。预期出现浅红提示：命中公开弱口令参照、避免连续序列。
2. 换成 `M7!rQ2@x`，再点击“本地检查”。预期本地基础检查通过。
3. 点击“检查本站私密要求”。在上述8–64基础条件下，预期“操作完成”。

本地检查只是在你的浏览器里提供提示；本站私密检查才会核验当前站点规则。两者通过都不等于已经注册。

## 2. 用户注册、输错口令、正确登录

在**用户助手 → 注册账户**：

1. 账户标识填 `aaa-tour-1011`，口令和确认口令都填 `M7!rQ2@x`。
2. “网站挑战”先留空，点击“私密注册”。
3. 预期“操作完成”，本人账户能够查看。保存该次成功注册对应的恢复凭证文件；文件可能下载两次，内容相同。不要把恢复文件给管理员。

然后右上角“退出”，进入**私密登录**：

1. 同一账户，先输入错误口令 `WrongDemo9!`，网站挑战留空。预期“认证未通过”。
2. 换成 `M7!rQ2@x`，重新登录。预期“操作完成”。

再切到**管理员 → 账户与任务**，点右上角“刷新”，筛选该账户。预期能看到账户标识、版本、启用状态，不能看到刚才输入的口令或该账户字符结构。

## 3. 网站确认用户登录：第三个页面的作用

在**接入网站样例**：

1. 点击“取得本站挑战”，复制出现的一串字符。
2. 切到**用户助手 → 私密登录**，填写本次账户、初始口令 `M7!rQ2@x`，把挑战粘贴到“网站挑战”。
3. 点击“私密登录”。成功后在下方“网站认证证明”点击“复制证明”。
4. 回到接入网站，把证明粘贴到“网站认证证明”文本框，点击“验证证明并建立会话”。
5. 预期显示“已建立网站会话：aaa-tour-1011”。
6. 再点一次验证，预期拒绝，提示挑战无效或已使用。

这里你登录的是接入网站；前面登录助手，是获得本人工具会话。证明让两个登录过程连接起来，网站始终没有口令输入框。

挑战有效期5分钟，只能成功使用一次。失败或过期时重新取得挑战、重新在助手登录，再复制新的证明。不能只取得新挑战却沿用旧证明。完成这一步后，在用户助手登录页面**清空“网站挑战”**；后续普通登录不要沿用它。

## 4. 管理员收紧要求：影响新注册，保留原有登录

在**管理员 → 注册动态策略 → 基础要求**：

1. 策略名称填“演练：新口令至少12字符”。
2. 最短长度12，最长长度64。
3. 规则片段只勾选“2. 长度至少12字符”。
4. 勾选确认，点击“应用公开基础要求”，等待“策略已应用”。

在**用户助手 → 站点连接**点击“刷新规则与连接”，然后进行两次对比：

1. 用已有账户和原8字符口令 `M7!rQ2@x` 登录，挑战留空。预期仍能成功：新注册政策不会直接锁住已有账户。
2. 到“注册账户”，账户换为 `tour-new-1011`，口令及确认都填8字符 `M7!rQ2@x`。预期拒绝，账户不创建。
3. 同一新标识，改为12字符 `N8!sT4@vK6#p`，再注册。预期成功。

拒绝的注册尝试也可能先下载一份恢复文件；只有成功注册对应的文件才生效。不要用失败尝试的恢复文件代替原账户凭证。

这一段展示注册阶段策略实际改变新用户的选择。管理员界面查看到的是结果和最小账户状态，不能查看新口令。

## 5. 管理员给存量账户布置整改：失败与完成

在**管理员 → 存量分布调整**：

1. 本轮分配上限填1。
2. 累计分配上限填“当前已分配人数加1”。例如仍是2，就填3。这是累计总上限，不是本轮新增人数。
3. 可点击“比较18类整改要求”，查看已有画像的含噪估计；这一步不需要发布新画像。
4. “批准并分配整改任务”中，只勾选“3. 长度至少15字符”，取消其他选项。
5. 勾选确认，点击“在预算内分配本人任务”。

在目前演示账户和上述新标识下，本轮会优先分配到 `aaa-tour-1011`。请先在“账户与任务”刷新并核对，显示待处理后再进行下列步骤。若你已另建其他 `aaa-` 账户导致本轮分配不同，以实际结果为准，不要把其他人的任务当成本人的任务。

回到**用户助手**，登录 `aaa-tour-1011`，进入“我的任务”，点击“刷新”。预期待处理，要求至少15字符。

1. 点“修改口令并处理任务”。账户确认是 `aaa-tour-1011`，当前口令填 `M7!rQ2@x`；新口令与确认填12字符 `R9!uV5@wL8#q`。
2. 预期拒绝。虽然满足网站的12字符基础要求，但不满足该账户的15字符整改要求。刷新任务，仍为待处理。
3. 当前口令仍填 `M7!rQ2@x`，新口令与确认换成16字符 `R9!uV5@wL8#qJ2!m`。
4. 预期成功，任务变为已完成。管理员刷新账户任务和总览，也能看到实际完成数增加。
5. 退出后用旧8字符口令登录，预期失败；用新16字符口令登录，预期成功。

这一步展示存量分布调整的执行闭环：管理员发出要求，用户真实改密后才计完成，拒绝和未响应都不能充当完成。

## 6. 管理员停用、重新启用账户

在**管理员 → 账户与任务**，筛选主账户，点击“停用”，等待完成。

在用户助手使用正确的新16字符口令登录，预期“账户已停用”。管理员再“启用”，重新登录，预期成功。这个操作控制账户访问，不替用户改口令，也不改变已完成的整改事实。

## 7. 可选：完整口令与结构联合阻断

在**管理员 → 注册动态策略**先点“从当前画像计算候选”。看到非基础候选“保持”是预期结果：当前尚无本站用户响应和重选成本确认，不会把它伪装成自动优化成功。

要实际体验联合限制，在下方“快照联合阻断 · 管理员手动制定”：

1. 结构勾选 `L10D2`，表示10个小写字母后接2个数字。
2. 完整口令热点勾选 `OTHER` 行的“名次1”。
3. 勾选手动确认，点击“应用实际联合阻断”。
4. 用户助手“站点连接”刷新规则，然后到“口令助手”逐个输入并点击“检查本站私密要求”。

| 用户测试输入 | 预期 | 用途 |
| --- | --- | --- |
| `abcdefghij72` | 拒绝 | 命中所选 `L10D2` 结构 |
| `Unique-Sample-Password-37` | 拒绝 | 命中已有验收快照的匿名完整口令名次 |
| `N8!sT4@vK6#p` | 通过 | 未命中两种限制，且满足12字符基础要求 |

这些合成测试值及匿名名次曾在本机验收中核对；不是从管理员页面读出的真实用户口令。本段使用已有冻结快照演示规则执行，不代表更新后的实时热门榜。管理员只能选择结构和匿名位置。

本地提示仍可能通过，本站私密检查拒绝，这是两种检查负责范围不同。隐藏限制给合并拒绝提示，不向用户透露具体命中哪个秘密字符串。

## 8. 可选：忘记口令、恢复、删除

先在管理员“回退策略”恢复到之前记录的基础版本，用户助手刷新站点要求。

在**用户助手 → 恢复账户**：主账户填 `aaa-tour-1011`，恢复凭证内容粘贴该账户成功注册时保存的完整JSON，新口令及确认填 `V6!nB3@rH9#tE4!k`。预期恢复成功，并下载新的恢复凭证；保存新文件，旧恢复凭证失效。

之后，用恢复前的16字符口令登录，预期失败；用恢复后的口令登录，预期成功。管理员没有替你恢复的秘密。

最后可在“我的账户”输入当前口令、勾选注销并点击“验证口令并注销”。预期账户消失、不能再登录。若要保留账户继续体验，不做注销即可。

## 9. 怎样观察统计变化，怎样结束

管理员刷新总览即可看实际账户、任务和策略变化。已发布画像仍显示原快照的统计，不能把它当作当前人口。

如希望观察注册或改密后的新画像，到“受保护画像”设置本次ε=1，点击“联合计算并发布”。等待约数分钟，在“运行作业”查看原编号；不要因等待重复提交。新画像是含噪估计，不能承诺某根柱子一定按真实新增人数准确增加。同一人口同一发布阶段的重复查询会返回缓存，不重复扣预算。

结束时回退之前记录的基础版本，并刷新用户要求。回退只还原政策，不还原用户口令，不取消已完成整改，不返还已经消耗的隐私和人数预算。

遇到策略过期，先去用户“站点连接”刷新；会话过期就重新登录；结果未知就继续查询原请求。不要连续多次点击来绕过提示。管理员能从“运行作业”和“决策与效果”核对真实执行结果。
