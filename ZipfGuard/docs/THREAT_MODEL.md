# 威胁模型

预算 40、以及旧演示里的 100、1000、10000，都是离线猜测次数：攻击者已经拿到口令文件，在本地逐条尝试。它们不是网站登录次数。`10^8` 如果出现在论文或别的攻击器里，也不能解释成在线登录。

攻击者知道公开的策略模板，所以候选集里预先放入这些模板的改写，而不是等测试口令漏出来再补。训练用训练集。验证集只用来选建议。测试集在方案冻结后使用一次。

冻结攻击：排序模型仍用修改前的训练集，只在修改后的测试用户上计分。自适应攻击：用修改后的训练集重新计数或重新拟合，再攻击修改后的测试用户。

分母在新协议里是测试用户数，不是不同口令数。头部质量和全体结果分开时，字段名会写明。重复猜测只保留第一次出现的原始序号。生成失败、超时或没有覆盖到的口令，名次视为无穷，在任何有限预算下都不算命中。不能把命中数叫做生成数。

论文口径复现走 `experiments/reproduce_htpg_baseline.py`，只解释和原文数值的异同。严格评测走 `experiments/robustness_protocol.py`。本地有 RockYou 和 MAYA 频数，不能因此声称已经复现论文的六数据集跨站猜测结果。
