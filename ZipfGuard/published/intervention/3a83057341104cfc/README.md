# 十万账户局部干预实验结果

本目录保存运行 `3a83057341104cfc` 的完整聚合结果、图表与核验记录。目标账户和独立开发出现记录各 100,000 条，PCFG 与马尔可夫模型（采用 OMEN 实现）的猜测预算分别为 1,000,000 次。每个后续新口令均须通过两模型的个体门槛。

三个局部组使用共同的 8 字符基础规则起点，均执行 6 轮，每轮通知并成功修改 2,000 人，后续总通知人数为 12,000。Yahoo! 全站迁移要求 98,643 人修改，单独展示。

| 方法 | 不同完整口令数 | 经验 W1 距离 | F 并集命中率 | A1 并集命中率 |
| --- | ---: | ---: | ---: | ---: |
| 8 字符基础规则 | 92,495 | 0.040946 | 16.627% | 19.058% |
| 随机分批 | 93,741 | 0.034866 | 14.637% | 16.472% |
| 初始排序 | 99,963 | 0.000284 | 8.632% | 10.046% |
| 动态调整 | 99,992 | 0.000071 | 8.096% | 9.613% |
| Yahoo! 全站迁移（独立对照） | 99,509 | 0.003072 | 0.523% | 1.208% |

并集曲线横轴 B 表示每个模型各尝试 B 次，合计最多 2B 次，重复命中只计一次。

## 查看结果

拉取仓库主分支后，在项目网页打开 `/intervention` 即可读取此结果。已发布的压缩聚合记录供展示台直接加载，查看结果无需准备原始口令语料或重新计算。

GitHub 可以直接预览 SVG 图和本页表格。HTML 报告需下载 [report.html](report.html)，用浏览器打开；GitHub 文件页显示的是 HTML 源码。
