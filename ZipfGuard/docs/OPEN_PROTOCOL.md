# 开放 Min_auto 协议与实现

更新：2026-09-26。配置 schema 为 zipfguard-open-v2，结果 schema 为 zipfguard-open-result-v2，攻击协议为 open-minauto-v1。旧闭集流程保留用于历史复现，不参与默认推荐。

## 数据到推荐的完整链路

~~~mermaid
flowchart TD
    D[真实带频次语料：完整扫描与出现次数抽样] --> S[train / tuning / validation / test]
    S --> T[train：频次头部与加权特征]
    T --> P[分布引导候选 + 常见规则系列]
    P --> R[每个划分独立计算 R0 / R1 / R2]
    R --> A[原始或响应后的 train 训练攻击器]
    A --> U[tuning 选择 n-gram 参数]
    U --> G[开放生成：策略过滤、去重、计费]
    G --> V[validation：自适应 Min_auto + 成本]
    V --> F[按需求选择并冻结]
    F --> E[test：选中策略与常见规则配对评价]
    E --> O[建议、无改进证据或无可行策略]
~~~

当前实现不使用测试目标列表约束生成，也不调用旧 response_candidate_space。攻击器缓存仅在一次配置固定的运行内生效，键包含训练/调参内容与策略；评价缓存也限定在该次运行及其固定划分内。

## 数据语义

默认按全部有效出现记录均匀、不放回抽样，再对每个字符串的出现计数做 60%/10%/10%/20% 多项分配。分别用于训练、攻击参数选择、策略选择和最终测试。相同字符串可以出现在不同划分；其同一次出现不会被复制。

频次格式移除计数字段后仅消耗一个分隔符，保留口令中的其它有效空格。解码失败、空值和控制字符会排除；记录排除行数、已知排除频次及计数未知行。样本内重复字符串合并；全文件唯一数与全局重复行审计尚未实施，不输出伪造的全局唯一数。

R0 在各自划分的经验分布上条件化。R2 的重新选择池只来自 train。生成器、阻断表、特征与超参数都不从 test 学习。来源真实性、频次对应独立用户以及跨站点泛化需要额外证据。

## 模型与预算

- frequency：按 train 频次和固定平局规则生成有限字典。
- dictionary-rules：以 train 字典为来源，按预注册变形顺序输出；不使用测试行序或目标过滤。
- character-ngram：长度先验与平滑 Markov 字符概率，在 tuning 选择阶数/平滑参数。采用精确后缀最优概率界的 A* 搜索和延迟兄弟展开，按概率顺序生成；没有 beam 截断。字符表仅来自 train，长度范围写入配置。
- pcfg：固定上游 b04bbdadfe8928fd1287fa73ad1aa46a297ff83a，纯 PCFG 模式，训练记录按频次展开或按预注册上限抽样。原始候选进入同一计费器，训练及生成目录隔离并自动清理。

预算 K 是每个模型的不同有效校验候选数。F 不利用新策略过滤；A0/A1 按公开策略过滤后模型内去重，随后连续计费。目标之外的候选同样计费。另存原始输出数、过滤数、重复数、预处理/计费耗时及上游 PCFG 生成量。

逐口令 Min_auto 的预算命中等价于各模型前 K 次命中集合的并集。不会把最大单模型命中率当作 Min_auto，也不把 K 解释为跨模型总猜测次数。PCFG 先受上游生成上限约束，再消费原始流；计算耗时与主校验预算分别报告。

停止原因包含 reached_budget、exhausted、raw_limit、timeout、memory_limit、expansion_limit。自然耗尽可延伸为固定算法平台；资源截断后的未命中状态未知，输出下界/上界及未决质量，并从完整风险推荐中排除。已被其它模型命中的目标仍能确认联合命中。

必选模型运行失败终止；可选模型失败后在整次比较中移除并重算。模型异常摘要不会导出可能含口令的第三方错误文本。

## 规则、响应与成本

M1 当前使用训练频次头部标签的加权信息增益比、支持度与方向选择特征。Zipf 等拟合是分布诊断；不能替代攻击命中率。交叉拟合的攻击命中标签尚未启用，报告明确 attack_labels_used=false。无分布引导消融按固定种子打乱特征库，保持相同候选数量和资源上限。

常见规则包括无约束、多档长度、长度加三类字符、长度加 train 高频阻断表。候选不得从 test 构建。阻断表原文仅在核心内使用，公开报告保留数量和哈希。

R0 为独立重新选择，接受概率为 a；成本为初始拒绝比例 1-a。无限重试的额外尝试期望为 (1-a)/a；有限总尝试 L 的完成率为 1-(1-a)^L，额外尝试期望为 [1-(1-a)^L]/a-1。a=0 为不可行，不能推荐为零风险策略。

R1 使用预注册的简单修补序列，遇到首个合规结果即停止，不声称找到编辑距离全局最优解。R2 混合修补、训练池重选与放弃。不同策略使用同一初始队列和固定共同随机数。拒绝率、尝试及编辑距离按全部初始用户计分母；攻击风险按完成账户计分母，同时报告完成率和全体用户中完成且被命中的比例。

## 选择与证据

主目标为指定响应下的 A1 自适应 Min_auto。cost_cap 在成本上限内最小化风险，risk_target 在风险要求内最小化成本；同时限制完成率、额外尝试和规则数量。常见规则也可被选中，不强制输出新规则。

推荐只在 validation 按所设需求选择并保存选择哈希；test 核查选中策略是否达到风险、成本、完成率和尝试约束。推荐表不以对照差值决定策略或测试判定。若单独研究相较常见规则的改进，则使用验证阶段同约束下选出的常见对照，并在 test 计算配对差异；选中策略本身是常见规则时不执行与自身的比较。不从测试集挑选对手。

配对 Bootstrap 以完整初始队列为单位；R0 每次重新计算条件分母。区间固定训练产物和选择结果，属于逐点探索性区间，不是完整训练搜索的不确定性或同时置信带。支持改进的标记要求风险与成本的区间下界均不劣，至少一个超过配置阈值，且测试需求满足；否则不声称有改善证据。

## 验证与研究范围

真实开发文件共 14,344,391 行。当前严格解析保留 32,603,039 次有效出现，排除 10 行、349 次出现；全量计数预检的 32,603,388 与之相差的原因已显式记录。该读取验证不等于来源真实性核验。

工程验收使用真实抽样 2,000 次出现，另有 400 次出现的三模型浏览器运行。正式大规模、多种子、跨来源及行为校准结果仍需单独执行。PassLLM/RFGuess、A2、真实用户试验和完整 HTPG 复现没有被伪装成已完成部分。
