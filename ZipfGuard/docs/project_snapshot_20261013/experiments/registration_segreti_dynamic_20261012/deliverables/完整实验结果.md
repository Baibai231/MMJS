# 同一Segreti名单起点的动态调整：完整实验

只新增运行动态方案。100,000条模拟用户记录，10批，每批10,000条，种子11。固定Segreti对照采用相同目标与开发分区的既有完整结果。

首批直接使用同一份213种结构名单，目标、开发结果及重选序列已逐项核对。每轮保留原始Segreti名单与当前名单，尝试在完整名单之外新增5或20种近期结构。预览累计联合风险只要比更好的基准低、并通过另一预览角色确认后，即启用新增规则；没有0.5个百分点的最低门槛。

所有候选、确认及最终攻击均使用PCFG与OMEN各百万次实际猜测。主联合结果最多使用200万次尝试，重复输出计入预算，同一账户只计一次。用户持续重选至接受，不设修改次数上限。
