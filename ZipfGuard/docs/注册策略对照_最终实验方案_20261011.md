# 注册策略对照：最终实验方案与开发修订

**状态:** 在新终测开封前冻结。每组十万用户、五个配对种子，最终仅保留报告相关实验。

## 1. 修订依据

原方案的校准显示：纯反事实收益列表的攻击收益较弱，理想精确计数流行度阈值显著更强。单次新候选校准显示，仅限制训练预测可猜中字符串的重复使用，有望保持阈值方案的攻击收益并减少提交成本。以上均为开发信号，不是终测结论。

用户随后要求仅做报告相关实验。旧实验进程已经核实启动命令后停止，源目录的终测开封记录不存在；复用其出现位置划分和已完成的基线校准。原开发输出保留，最终输出单独保存。没有根据新终测效果修改方案。

## 2. 最终方案：攻击风险选择与成本约束的在线流行度控制

令 $P_0$ 为共同基础规则，$C_t(w)$ 为所有完成注册账户中字符串 $w$ 的计数，$N_t$ 为已完成注册账户数。基于独立开发训练用户经基础规则转换的 PCFG、OMEN 前缀，定义 $G_B$ 为两模型各 $B/2$ 次实际尝试的命中字符串并集。

$$
\operatorname{Accept}_t(w;r)=P_0(w)\land
\left[w\notin G_B\ \lor\ C_t(w)=0\ \lor\ C_t(w)<rN_t\right].
$$

所有成功注册的字符串均计数，但只有训练预测器判定可猜中的字符串受到附加流行度限制。这与 Schechter 的所有字符串流行度阈值不同，可以检验减少无效拒绝的收益；不代表未在前缀中命中的字符串已经安全。

首批统一用基础规则启动。每批后从过去账户计数克隆候选状态，不修改真实状态；对六个流行度阈值及当前阈值模拟同一预览用户序列。阈值网格为 $10^{-6},10^{-5},3\times10^{-5},10^{-4},3\times10^{-4},10^{-3}$。

$$
\widehat R_t(r)=\frac{N_{t-1}\widehat R(H_{t-1})+n_t\widehat R(Q_t(r))}{N_{t-1}+n_t}.
$$

选择成本合格且等总预算一百万预测命中率最低的阈值，风险相同时优先额外提交较少、阈值较宽者。累计预测改善至少 0.05 个百分点才尝试更新，使用不同确认角色确认唯一赢家；成本不合格的当前阈值可以由确认合格的替代者取代，无合格候选时回退基础规则。

选择与确认各 6000 名预览用户，各自独立角色和过去两批初始口令各占一半；共享历史，不声称完全统计独立。较小预算预测命中率增加不得超过 0.2 个百分点，两个模型均不支持的比例增加不得超过 2 个百分点。这些是同一次策略选择的保护条件，不另开防护机制实验。

**开封前覆盖定义修订:** 校准发现原保护条件仅用 PCFG 支持域，会将仍受 OMEN 支持的字符串误记为联合模型外，从而排除有效候选。现统一使用“PCFG 概率为零且不在 OMEN 声明长度与字符域内”定义联合模型外；PCFG 单模型外仍单独报告。未命中前缀与模型不支持分开处理。原定义的校准及封存记录归档，相关控制器校准重新执行，基线校准复用；终测尚未开封。

预测器保持固定，最终评价重新训练各策略条件化的开发训练攻击器。固定预测器下过去账户风险对候选是常数，历史累计项主要影响更新门槛；不宣称已经解决攻击者实时重训练或获得真实安全证明。

## 3. 仅保留两项最终实验

| 实验 | 正式组别 | 目的 |
| --- | --- | --- |
| 文献机制 | 校准热点刷新、Schechter 理想计数阈值、Malone–Maher 概率拒绝、当前联合控制器、最终风险选择方案 | 比较两篇不同论文机制、较强简单刷新与已有项目实现，确认新方案的实际优势及成本 |
| 网站规则 | GitHub 公布的长度类别核心、网站核心加公共黑名单、上述基础加最终风险选择方案 | 比较真实公开网站规则，并分离公共黑名单收益与动态控制收益 |

每组十万用户分十批，每批一万；种子为 11、23、42、67、101，共 40 条正式方法轨迹。未另设行为敏感性、多场景漂移、更多攻击器、防护机制或结构消融实验。

文献实验共同基础为长度至少 8 与训练频次前 1000 公共黑名单。修改率不超过 60%、平均额外提交不超过 1、额外提交超过三次的比例不超过 5%，必须全部完成。

GitHub 核心为至少 15 字符，或者至少 8 字符且有小写字母和数字，未复现服务端全部检测。网站附加控制相对“核心加公共黑名单”的最终字符串变化不超过 20%、平均正向额外提交差不超过 0.5、正向提交差超过三次比例不超过 5%，必须全部完成；报告绝对成本，不能称严格同成本。

## 4. 校准、数据与终测

刷新容量在 100、1000、3000、10000 中选择；Schechter 阈值使用同一六值网格。选择全部五次成本合格者中平均固定预测主指标最低的参数。Malone–Maher 按原机制执行，不另加弱化系数；当前联合控制器保留未修改实现。新控制器的网格与确认规则在此冻结，不用终测选择超参数。

新抽五十万校准和五十万终测出现位置，排除上一轮全部五十万位置；保留训练六万、两个预览角色各一万和未用的调参角色两万。五次终测位置互不重叠，两类实验共享同一组用户。相同字符串可以跨角色出现，出现位置不能重叠。

所有方法共享策略无关的提议序列：沿用 60% 修补、25% 短语、15% 重选及确定性长度补齐，不给新方案额外高熵修补。该模型不代表已经验证的真人行为。

最终 PCFG、OMEN 只用开发训练用户的响应拟合，不用目标明文；列表规则公开给攻击训练转换，在线频数机制在开发用户中独立运行。开发人数六万与目标十万的差异必须报告。两攻击器各生成一百万实际尝试，重复计费；预算曲线为 100、10000、100000、一百万。主指标为等总预算联合命中率，另报各模型、成本、完成率和模型外比例。

## 5. 结论与创新规则

研究假设是：对“训练预测可猜中”的口令选择性限频，可以比全字符串限频减少无效拒绝；按共同成本预算在线调整阈值，可能取得更好的实际风险与成本权衡。动态生成、流行度控制、攻击者视角及重选模拟已有研究，不宣称首创这些概念。是否超过已有方法由实测结果判断。

攻击优势门槛为等总预算主指标降低至少 0.5 个百分点、至少四次同向、全部成本合格。成本优势单独报告，不能用成本下降掩盖攻击风险明显上升。若攻击改善不足 0.5 个百分点且额外提交更少，可报告“攻击均值相近且提交较少”的描述性结果，不能声称等效或安全优越。

五次配对报告百分点差、近似 t 区间和双侧符号翻转值；五次全同向时双侧最小值为 0.0625，不硬写 5% 显著。负结果、预算差异、模型外和实现适配必须保留。新颖性和引用待作者人工核验，不伪称已经投稿批准。
