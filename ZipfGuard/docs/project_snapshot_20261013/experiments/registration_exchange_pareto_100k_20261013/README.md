# 编辑量感知双向调整 v2：单组十万用户复测

本轮同时改善了猜中率和修改负担。两模型各一百万次实际尝试下，联合猜中率为 7.490%，人均额外提交为 1.48240 次，平均编辑量为 3.87207 字符／全部用户。

相对上一版 v1：联合猜中率相对下降 20.58%，额外提交相对下降 36.80%，平均编辑量相对下降 29.08%。固定 Segreti 的攻击与提交指标和 v1 一致；固定组原编辑量未测，v1 已测。

仅新增 v2 一个完整十万用户轨迹，八组历史数据只读复用。完整结果、对照图和数据位于 `deliverables/完整结果与比较.md`；原始实验目录见 `canonical_root.json`。

原成本准入条件及六个重训名额保持，改动为编辑量前移、Pareto 候选保留和解除后重新计算组合编辑。共享响应重放、摘要一致性等八项相关检查通过。九轮粗筛的缓存与原模拟结果逐项相同，最终攻击前缀与用户账本重新核对，图表已作视觉检查。

本轮为旧目标流上的单次探索，不能据此证明跨用户稳定领先、真人使用体验或对所有攻击者有效。没有覆盖 v1 实现、配置或结果。
