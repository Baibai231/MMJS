# 五方案对照：图注与结果论述

## 图注

图 X　全量10万模拟用户下五种策略的攻击效果与注册成本。（a）PCFG与OMEN的联合猜中比例，横轴为两模型合计实际猜测次数，各模型分配一半预算；猜中同一账户只计一次，重复猜测仍计入预算。（b）用户第一次提交之后，人均额外提交次数。Schechter采用本轮严格档；Segreti为统一模拟条件下的结构黑名单机制适配；GitHub仅使用公开长度与字符要求。每种策略分10批注册，仅展示第一轮结果，没有跨轮次误差条。

## 结果论述

图X比较了我们的改进方案、Schechter严格档、Malone–Maher、Segreti结构黑名单以及GitHub公开核心规则。各方案均使用同一批10万模拟用户，分10批注册。攻击评价采用PCFG与OMEN联合猜测，两模型各分配一半总预算；用户成本采用首次提交后的人均额外提交次数。

在合计10万次猜测下，我们方案的猜中比例为5.737%，低于Schechter的9.827%、Malone–Maher的15.361%和GitHub公开核心规则的20.652%，分别下降4.090、9.624和14.915个百分点。在合计100万次猜测下，我们的方案仍低于上述三个对照。我们方案的人均额外提交次数为0.7288次，与Schechter的0.7138次接近，说明本轮相较Schechter的安全效果改善只增加了较少的提交负担。

Segreti的猜中比例更低：合计10万次猜测下为3.881%，我们的方案比它高1.856个百分点；合计100万次猜测下，二者分别为13.608%和7.733%，相差5.875个百分点。但Segreti的人均额外提交次数达到2.3457次，我们的方案降低了68.9%。因此，本轮结果支持的优势是：与Schechter、Malone–Maher和网站公开规则相比，我们的方案在主要攻击预算下有更低的猜中比例；与Segreti相比，则以一定的安全效果差距换取大幅降低的注册负担，提供了另一种安全性与使用成本之间的选择。这些结论来自一次模拟，不表示安全效果与Segreti等同，也不代表原论文真人实验的全部结果。
