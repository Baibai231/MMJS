# 外部验证设计

本文件是计划，不是已完成的效果实验。

## 语料角色

| 语料 | 角色 | 不能当作 |
| --- | --- | --- |
| 带频次 RockYou | 分布核对 | 已证明的论文原件，或跨站攻击结论 |
| MAYA 000webhost、Yahoo | 同名外部拟合 | 表 I 原件 |
| MAYA 其余站点 | 外部泛化 | 178、CSDN、RenRen 的替身 |
| 合成 652 支持集 | L0 回归 | 真实用户或原场景 |

MAYA 频数是重复行出现次数，不是已核验的账户人数。站点之间的相同字符串要报告重叠，不能声称天然零交集。

## 攻击候选

真实语料上的攻击候选只能来自允许的训练信息、公开模型和事先写明的生成规则。不能用测试口令补候选，也不能把合成支持集的闭包搬去当真实口令的答案目录。
