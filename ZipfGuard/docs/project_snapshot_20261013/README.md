# TriGuard 当前项目归档（2026-10-13）

本目录保存本次同步时的报告、图示和可公开实验结果。主项目源码位于仓库的 `ZipfGuard/` 中。

- `report/overleaf/`：从最新 Overleaf 提交导出的 LaTeX 源码、文档类与全部受版本管理的图片；使用 XeLaTeX 编译 `main.tex`。
- `figure_sources/`：方案图的可编辑绘图脚本、SVG 和预览图。
- `experiments/`：按原始实验目录保存的结果、图表、配置记录与核验文件。
- `manifest.json`：源文件位置、文件哈希及 Overleaf 提交号。

实验目录包含历史对照、探索性实验和当前结果，结论以相应配置、状态、核验记录及最新报告为准。归档不会把尚在研究中的方法作为已验证成果。部分脚本保留原本机路径，复现时需要调整数据路径；受控语料、模型缓存、运行数据库、私钥及客户端凭据留在本地。
