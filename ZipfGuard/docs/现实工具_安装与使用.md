# TriGuard 双端工具：安装与使用

这是新建的工具，与原研究展示网站独立。用户通过浏览器扩展输入口令，管理员通过另一个来源的管理网站操作。三方计算服务持久保存各自的一份秘密，业务服务只取得认证结果、公开策略、本人任务和受保护汇总。

## 1. 本项目直接启动

当前电脑已额外配置 [直接可操作展示](现实工具_直接查看.md)：双击 `打开可操作展示.cmd` 会启动服务并打开已登录的本机演示管理台及用户助手。下列方式保留普通管理员设备通行密钥的手动登录流程。

当前项目已安装依赖并构建两套应用。运行项目目录下的 `启动完整工具.ps1`；停止时运行 `停止完整工具.ps1`。

启动器打开专用本地演示浏览器配置，自动加载用户扩展，并打开管理台与接入样例。它不会改变普通浏览器资料或操作系统证书信任。此专用配置为本地测试证书设例外，同时禁止解析外部域名；请只用于本机演示。正式部署必须使用受信任HTTPS。

如果当前Chrome版本禁止通过启动参数加载扩展，在这个专用配置内打开 `chrome://extensions`，启用“开发者模式”，选择“加载已解压的扩展程序”，选中 `apps/user-assistant/dist`。扩展压缩包需先解压，再加载其中包含 `manifest.json` 的目录。不要把口令填写到接入网站的网页表单。

| 应用 / 服务 | 本机入口 | 职责 |
| --- | --- | --- |
| 用户应用 | 扩展弹出入口 → 完整用户助手 | 本地检查、注册、登录、迁移接入、改密、任务、恢复、注销 |
| 管理员应用 | `https://localhost:8532` | 画像、策略、存量调整、账户任务、作业、接入及权限 |
| 接入网站 | `https://localhost:8560` | 接收三方认证证明，建立自己的网站会话 |
| 用户业务API | `https://localhost:8531` | 用户身份与本人业务，无明文口令接口 |
| 三个计算方 | `https://localhost:8541` 至 `8543` | 各自接收一份秘密，联合计算及签署结果 |

也可以在安装目录执行：

```powershell
.\.venv\Scripts\python.exe ops/tool.py start
.\.venv\Scripts\python.exe ops/tool.py health
.\.venv\Scripts\python.exe ops/open_local_demo.py
.\.venv\Scripts\python.exe ops/tool.py stop
```

如果提示已有进程记录，先执行停止命令，再启动。所有服务就绪后再操作。后台画像运行时交互操作可能排队，请保留请求编号，不要重复提交。

完整54维画像在本机7个合成账户上的一次确认发布实测约200.45秒，其中节点计算约197.39秒。这是后台计算的真实等待时间；没有验证大型网站容量。已有快照的查询无需重算。

## 2. 管理员首次使用

打开管理台，选择“首次安装 / 接受邀请”，填写自己的管理员标识。安装凭证保存在私有文件 `tool_runtime/administrator-installation-code.txt`，复制到安装凭证输入框。然后使用Windows Hello、设备通行密钥或FIDO2安全密钥完成登记。浏览器验收使用虚拟认证器验证WebAuthn流程；普通使用应配备自己的认证器。

安装凭证一次有效，默认有效期一天。过期后由本机部署操作者生成新凭证：

```powershell
.\.venv\Scripts\python.exe ops/new_installation_invitation.py
```

负责人可在“权限与设置”邀请操作员或只读审计员，修改角色和停用身份。权限在后端检查，隐藏菜单不能替代权限控制。

管理员功能：

1. **运行总览:** 当前要求、实际参与账户、未迁移的历史保留账户、真实任务完成数、预算及节点状态。
2. **受保护画像:** 发布结构人数、结构内匿名频次及18类规则违反人数。相同人口快照缓存发布；“独立确认发布”使用独立噪声并额外扣预算。
3. **注册动态策略:** 制定公开基础要求；运行联合候选计算；在缺少响应模型或确认依据时保持当前策略；通过单独标注的手动面板，选择结构和匿名完整口令名次并实际应用联合阻断；回退历史要求。
4. **存量分布调整:** 比较18类要求的含噪估计，在每轮和累计人数预算内批准三方秘密资格判断及任务分配。停止计划不伪造已分配任务的完成。
5. **账户与任务:** 最小账户标识、凭据版本、任务状态、停用与启用，没有逐账户口令结构。
6. **决策与效果:** 记录保持、应用及实际操作结果；导出批准汇总。覆盖估计、真实完成和无法估计的攻击收益分别标注。
7. **运行作业:** 排队、运行、完成、失败、未知结果、取消未执行作业及沿用原编号核对重试。
8. **网站接入:** 下载公开配置，打开独立接入样例并按步骤自检。
9. **权限与设置:** 角色、定期画像发布、业务记录保留及独立备份说明。节点秘密备份不提供给管理台下载。

自动评审按配置的新增注册批次触发，或按已授权的定期发布安排运行。缺少当前人口画像时先排队发布；具备画像后比较候选并记录“保持”的依据。自动评审不能跳过隐私预算，也不会补造用户重选收益。

“自动候选保持”和“管理员手动制定”具有不同的证据含义。手动联合阻断证明策略能够执行，不能声称未来重选成本和攻击收益已经得到模型保证。

## 3. 用户使用

口令只在扩展页面输入。支持8–64个可打印ASCII字符，站点可以在此范围提高最低长度；不支持的字符或超长输入会拒绝，不会静默截断。

1. **口令助手:** 输入候选，先看本地公开检查；连接站点后可限次检查本站私密要求。公开规则参照不是概率攻击排名模型。
2. **站点连接:** 查看计算方身份，切换、移除或导入站点。新配置必须由安装包固定的独立发布者签名；核对后只授予该站点所需地址权限。
3. **注册账户:** 填写标识与两次口令，提交同一秘密用于检查、凭据及贡献。恢复凭证在提交前下载，请保存；只有注册确认成功后对应凭证才生效。
4. **私密登录:** 三方核对候选与分布式凭据，相符后签发有限会话。新注册要求不会锁定原有口令登录。
5. **存量账户接入:** 在已授权的网站取得短期迁移证明，在助手内登记新秘密。迁移不能覆盖已经加入三方服务的账户；历史加盐哈希不能直接转成精确口令分布。
6. **我的账户:** 查看本人资料与历史，退出或验证当前口令注销。注销移除当前贡献，历史隐私预算不返还；重新注册不会复活旧会话。
7. **修改口令 / 我的任务:** 验证当前口令并检查新口令；成功后原凭据失效、当前贡献替换一次，待处理任务完成。失败、退出或未响应都不算完成。
8. **恢复账户:** 粘贴本人保存的恢复凭证，输入两次新口令。恢复秘密用于本地签名，不上传；成功后轮换凭证，旧恢复凭证失效。

助手不保存明文口令历史。本人会话在应用内存中；可信站点配置只存扩展自己的存储。已上传请求的公开上下文与结果查询凭据可保留在扩展的会话存储，以便刷新后继续查询，不保存口令或份额。扩展会话存储会随浏览器会话结束而清空。JavaScript环境不保证物理内存立即擦除。

用户会话有效期15分钟，同一个认证回执重复提交只能取得原来的有效会话。退出、过期、凭据变更或停用后，该回执不能再次签发新会话，需要重新私密登录。

如果出现“结果未知”，先使用“继续查询原请求”，或登录查询账户状态。计算完成后业务核对服务会修复允许的账户与任务状态，不需要重新上传口令。

## 4. 网站接入演示

在独立接入网站取得一次性挑战，将挑战填入助手注册或登录页面。完成后复制“网站认证证明”，粘贴回接入网站。网站验证三方签名、站点、挑战和当前凭据版本，建立自己的安全会话。重复挑战不能使用。

接入SDK位于 `sdk/zipfguard.py`。历史迁移授权函数必须放在网站已经验证原有用户会话之后调用；不能根据任意前端提交的账户名称签发。计算方仍独立阻止覆盖现有私密凭据。站点及各节点需配置一致的历史保留账户标识及迁移签发公钥。

## 5. 移到另一台机器

安装Python与Node，解压完整工具源码包，在工具目录执行：

```text
python ops/setup_tool.py
python ops/tool.py start
python ops/open_local_demo.py --browser YOUR_CHROMIUM_EXECUTABLE
```

完整安装会重新生成本机密钥、扩展身份和公开信任配置，并构建应用。不要把测试机器的私钥、份额数据库或恢复文件发给其他人。

正式独立部署参阅 [部署说明](../deploy/README.md)。三个计算方使用各自私钥、数据库和独立保留账本。数据库支持PostgreSQL；本机使用SQLite。部署模板可配置分地址服务，但本次尚未完成跨主机部署与生产安全审计。

## 6. 备份与恢复

本方操作者使用 `ops/backup_tool.py` 备份自己的份额目录，外部单调账本与备份分离。节点每次额度消耗及共同提交会更新保留账本。恢复前停止服务；恢复不返还隐私预算、查询额度或任务预算。缺少已经提交的新凭据份额时拒绝旧备份恢复，不能由其他方补发明文口令。

本机 `highwater.json` 用于验证恢复行为；它与所有节点仍由同一台电脑控制。正式部署应把各方保留账本放在独立留存或WORM存储，不能允许备份同时回滚全部可信账本。

## 7. 验证范围

详见 [验收与边界说明](现实工具_验收与边界.md)。界面、真实协议、规则、任务和故障流程已经采用合成数据验证；画像仍是昂贵的后台计算，性能仅按实测小样本报告。源码包和安装包不包含运行私钥、份额、管理员邀请或恢复秘密。
