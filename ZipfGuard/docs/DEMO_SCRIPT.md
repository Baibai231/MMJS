# 5 到 8 分钟演示

1. 问题：常见口令集中在分布头部。建议如果只按特征的信息增益排序，不一定降低给定预算下的猜中率。
2. 论文复现：打开 RockYou 拟合结果。前 1,171 名频数和是 3,899,108。α 三位小数是 0.914。曲率切分是公式算出来的，比论文公布的排名大约多 1，没有改写成 1,171。总量差 93,107 仍是未解差异。
3. 新建议：同一批候选特征里，验证集比较执行建议前后的 `cracked@40` 和修改率。测试集不参与选择。
4. 同预算若打开 `reports/directed_size900.json`，要说明它是执行器修正前的 `robustness-v2` 记录。长尾和 Zipf、900 用户、预算 40、五种子：长度加黑名单大约下降 16.1 和 7.6 个百分点；论文 unique IGR 和预算/成本都是 0。之前约 17.9 个百分点来自大约 19% 的口令掉出候选集。0 也不是“新方法已经成立”的结论，当前 `robustness-v3` 还没有重跑。
5. 边界：这是合成用户。MAYA 只说明分布和特征排序没有照搬过去。没有用户研究，就没有实测记忆率。比赛名称和截止日期还没有外部文本。PassLLM 未参与。固定阶马尔可夫不是 OMEN。576 项演示在预算不小于 576 时会标明候选已被穷尽。建议动作现在跟着尾部目标走：尾部更多大写时建议是使用大写，不是一律取消大写。

问答口径：

- IGR 高只说明头尾标签分得开，不自动等于猜中率下降。
- PCFG 或马尔可夫的空间外猜测仍占原始序号。过滤后再从 1 编号会把名次说小。
- 攻击者知道策略模板，所以要看自适应攻击，不能只报冻结攻击。
- 用户只在末尾加一个符号，是传统规则的一种反应；模拟里它不一定降低自适应频次攻击。
- 真实口令不出现在报告、网页和 `summary()` 的默认输出里。合成演示若显式打开猜测，会标明那是语法字符串。
- 没有多站点明文评测时，不能声称真实跨站防御。MAYA 的结果是拟合和排序迁移，含英文词表在非英语站点上的失败。
