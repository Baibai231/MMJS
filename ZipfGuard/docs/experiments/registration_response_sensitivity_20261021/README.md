## 结果边界

两种比例下动态方法的适应性联合命中率均低于Segreti静态策略，修改成本也较低；冻结攻击下静态策略更好。80/15/5下动态方法适应性命中率高于60/25/15，不能宣称行为比例不影响结果。单种子不能支持统计显著性或跨数据源泛化结论。
