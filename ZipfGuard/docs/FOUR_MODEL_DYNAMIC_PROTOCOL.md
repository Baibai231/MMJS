# 四模型统一评价与动态策略继续实验方案

日期：2026-09-30。本文件是实施方案，不代表 960 条四模型评价或 $P^{10}$ 路径搜索已经完成，其中 $P$ 为最终候选策略数。沿用所有注册用户保留、每批重新选一条完整策略且允许重复、所有方案共享同一用户顺序和修改机制的设定。

## 统一的实验契约

1. 四模型使用相同且互不重叠的开发训练、调参和评价用户。F 用原始开发训练，A0 过滤 F 的同一原始候选流，A1 用按策略修改后的开发训练重新拟合。冻结超参数、用户顺序、响应种子与模型随机种子；模型不能读取评价口令。
2. 主图的横轴为**每个模型**已经完成的去重、符合当前策略的有效猜测数 $B$，依次取 100、1,000、10,000、100,000、1,000,000。联合命中表示四模型各有 $B$ 次预算，并集上限相当于四倍预算；逐模型曲线和联合曲线都展示。原始抽样、重复、无结束符、策略过滤、墙钟时间和训练时间分别记录。
3. 一个模型只有真正达到 $B$ 条有效猜测，或其确定性有限候选空间被证明确实穷尽，才可写作该预算已完成。超时、输出上限和重复导致的短缺报告已观察命中下界与未知上界，不能填零或参与完整预算的优劣排序。
4. 评价主表始终以全部用户为分母，附模型各自的支持范围和范围外人数。比较模型本身时另给共同支持域的敏感性表，但不从主实验删除长口令或非 ASCII 用户。训练过滤和生成能力的差异都写入报告。
5. 模型允许采用各自经过验证的最强生成方法。统一的是训练信息、有效猜测预算和完成判据，而非强行令 OMEN、PCFG 和神经模型使用同一种搜索算法。生成方式、概率排序是否精确、计算资源和随机种子是报告字段。随机模型至少重复若干预先固定的种子，展示波动；不能只挑有利的一次。

## 逐模型适配

| 模型 | 当前可用路径 | 下一步调整与验收 |
| --- | --- | --- |
| OMEN | 原作者 C 实现、三阶、长度最多 19、可打印 ASCII 不含空格；量化概率顺序 | 保持纯 OMEN 和固定阶数。把原始输出上限改为可续跑或分段增长，直到 $B$ 条有效猜测或明确超时；对 A0 尤其不能只检查 F 的前 $B$ 条。记录长度和字符范围，另测各长度段吞吐。不要将长口令自动判为安全。 |
| 纯 PCFG | 原作者纯 PCFG；开发训练上限 10 万，正式原始输出上限 100 万 | 保持纯语法生成，不混入其内置 OMEN。将当前等于最大有效预算的原始上限拆成更大的资源上限或可续跑流；否则 A0 一旦有过滤就不可能完成 100 万有效猜测。优先复用相同训练语法，保存确定性排序和原始位置。 |
| PassGPT | 作者分词和训练组件；正式 8 层架构尚无百万预算测速，当前按采样顺序计猜测 | 固定正式架构与训练轮数，开发集从随机初始化训练。先对采样结果保存模型分数并去重、排序，明确标为“采样池内排序”；再评估受资源约束的概率优先搜索。排序规模、漏掉结束符的次数和实际有效输出都要记录。GPU 若可用先校准训练、生成吞吐，不能用小架构成绩代替正式模型。 |
| PassLLM | Qwen 0.5B、独立开发 LoRA、作者通用提示词 ID 1 与随机采样；CPU 小样本约 5–6 次原始采样/秒 | 保留独立训练，作者 RockYou LoRA 仅用于接口复现。先把作者通用 Two-Stage / Divide Search 做成资源有界、可中断、可审计的单独生成模式，统一候选排序和去重；随机采样与 Divide Search 分列，不混称。需要实测 GPU 或其它加速和更大批量；单次 100 万原始采样的 CPU 小样本外推约 49 小时，当前一小时生成上限不足。 |

四模型的有效预算可以一致，原始输出上限和运行时间不宜机械设成相同数值。按每个模型达到 $B$ 所需的重复率、过滤率和吞吐预估资源；仍达不到时公开未完成。对每模型另报生成计算成本，使攻击强度和计算代价都可比较。

## 动态选策略的继续路线

三张目标图继续分别比较：最终口令碰撞概率、四模型在指定完整预算下的联合 A1 命中率、用户修改率与后期批次额外成本。三个目标分别列 Top 10，并同时展示修改成本上限下的可行性；不把三个指标临时加权成一个未经约定的“综合最优”。攻击未完成的方案以区间显示，不与完整值直接排序。

1. 继续保存 960 条完整候选的注册分布与修改成本结果。攻击模型换版后，旧频率／字典／n-gram 命中率只作为历史结果。冻结 15、30、60 或更多条之前，先用四模型在能**共同完成**的低预算评价候选，检查机制覆盖、成本、碰撞与攻击指标的稳定性。低预算筛选是经验缩小范围，不能证明其他模板在百万预算或所有动态历史中永远无用。
2. 先在小候选数、小批次数上暴力枚举全部路径，验证策略重复、完整状态缓存、同分顺序及三个目标的 Top 10。之后扩展到十批；第一批仍可从 $P$ 条中自由选，因而结构空间是 $P^{10}$。评估动态反馈增益时，为每条路径另配**相同首批策略、相同用户与相同成本上限**的固定策略对照；固定“长度≥8”可保留为预设参照，但不能单凭与它比较归因于动态反馈。
3. 对注册分布和修改成本使用已证明的前缀下界做精确分支剪枝，并合并对未来完全等价的状态。等价状态须包含历史口令频数、历史黑名单、开发训练变化、响应随机状态与已累计成本；每个状态若要保留 Top 10，不能只保留一条代表路径。逐深度记录已完整评价、已证明排除和未解决的路径数。
4. A1 的神经模型在未来批次重新训练，候选流可能改变。现有旧攻击下界不能保证新四模型的全局攻击 Top 10；在无新证明时，攻击分支下界只能取零。对完整路径可先做低预算攻击，再按已观察命中下界决定是否值得继续算更高预算；这只能安全地节省**单条完整路径的后续计算**，不能自动排除它的所有未来分支。
5. 如果 $P^{10}$ 的未解决数不能归零，就发布“当前最好路径、完整评价数量、严格排除数量、仍未解决数量”，把束搜索或其它启发式结果明确标为近似。对最终入选的动态路径、统一首批的固定对照和无策略基线，再做四模型更高预算审计。某预算只在四模型和比较方案均完成时用于确定性排序；其余报告风险区间。

离线枚举使用整条未来注册序列，所得“最优路径”是**事后最优参照**。实际动态控制器在第 $t$ 批只能读取前 $t-1$ 批分布和已授权的开发数据，不能提前知道未来用户口令。两者分别画线、分别命名；只有后一种才可用于论证历史反馈是否带来可部署的增益。

## 下一轮实施顺序与停止条件

先修正 PCFG 百万有效预算不可能由百万原始上限完成的问题，并给四模型输出加入统一审计字段；随后以 $10^2$、$10^3$、$10^4$ 梯度测量每模型有效产出率与时间。神经模型完成候选排序方式核验后，才用四模型共同完成的预算重新检查 960 条池子的攻击表现。与此同时，动态路径的分布和成本精确搜索可继续实现和验证，不必等待百万预算攻击。

正式结论有两个独立门槛：候选池具有公开的经验筛选依据；若宣称十批攻击的全局 Top 10，则未解决路径数必须为零。若任一门槛尚未达到，展示阶段性动态结果和相应限制，不将其写成全局最优。
