# 注册阶段联合动态策略：全量实验执行说明

**状态:** 2026-10-11 的运行协议与实现说明；小规模核验不构成策略优劣证据，全量结果以运行目录为准。

## 实验实现

新实现独立于旧 Top15 和已有账户干预实验。调整动作是完整口令与字符结构热点集合的联合阻断规模，以及冻结原集合的保持动作。所有方法共享出现记录、用户身份和与策略无关的候选偏好序列；长度修补使用确定性填充，避免以随机长尾填充制造安全收益。

控制器只读取已发生的注册统计和首次提议。候选攻击训练只用训练角色中的原始记录及其模拟响应；近期用户提议只能通过结构比例重加权进入训练，不能复制目标口令。选择和确认使用两个独立预览角色。确认一次失败即保持，不用确认池重选第二名。候选在攻击拟合前先接受成本筛查；全部不可行则记录约束冲突并回退公共基础规则。

对应实现为 `policy/registration_joint.py`、`experiments/registration_joint_data.py`、`experiments/registration_joint_pipeline.py` 和 `tools/run_registration_joint_study.py`。原理论协议见 [注册阶段动态策略_理论与实验方案.md](注册阶段动态策略_理论与实验方案.md)。

## 在终测前预先声明的补充和落实口径

1. 每条注册轨迹仍为 100,000 人、10 批。验证和终测各预留 200,000 条出现记录，以支持从训练资料确定的两个长度子群构造十万人合成变化流。各条轨迹内部无放回；不同场景、种子允许复用同一角色中的记录，这是同源模拟重复。
2. 一次全局角色划分：训练 60,000、调参预留 20,000、选择预览 10,000、确认预览 10,000、验证预留 200,000、终测预留 200,000。调参预留角色未进入候选模型训练或控制；固定对照参数通过验证注册池的校准阶段选择。ASCII 可打印字符为主实验口径；非 ASCII 频次和无效行另计。
3. 子群规则是训练角色的口令长度中位数 $d$: A 为长度小于 $d$，B 为长度至少 $d$。长度属于结构特征；规则在攻击评价前确定。开发攻击训练的合成场景使用训练角色自身的有放回加权模拟，生成独立模拟身份并记录训练来源，不能解释为新增独立自然人。
4. 原绝对成本协议保持：修改率不超过 60%、平均额外提交不超过 1、超过 3 次额外提交比例不超过 5%、无待处理用户。基础长度要求与公共阻断表本身也接受审计，不默认可行。
5. 额外执行独立的**相对公共基础规则的新增成本协议**：最终口令相对配对基础结果发生变化的用户比例不超过 20%，平均新增额外提交不超过 0.5，超过 3 次新增额外提交的比例不超过 5%，仍无待处理用户。这组单独校准、验证、封存和终测，结果位于 `incremental_cost` 子目录，不能充当原绝对门槛的通过结果。数字属于事前工程预算设定，不是文献最优值。
6. 最低长度 15 在 `length15` 子目录独立校准、验证、封存和终测，不沿用长度 8 的验证冠军。
7. 当公共基础规则已经违反绝对成本要求，可严格排除接受集合更窄的校准参数：共享候选序列下，其额外提交次数不能减少，初始被基础规则拒绝的口令不能直接被接受；未完成也不符合可行性要求。此类参数保存 `screened_cost_ineligible_by_common_base_lower_bound`，未执行完整轨迹，其成本字段标为下界，攻击指标缺失，不能冒充实测。
8. 主响应保留局部修补、片段重组、独立重选权重 0.60/0.25/0.15；局部操作与常见尾缀是模拟假设。混合权重、最小修补和独立重选另做敏感性。耐心 3/5/10 指最多额外重提议次数，首次提交不计其中；退出是模拟压力情景。
9. 主场景达到 1,000 个候选仍未完成时保留待处理，不静默删除训练记录。发生这种训练状态时继续模拟全部目标注册，报告 A1 无法有效拟合。耐心实验则明确计数退出者，只在已完成的开发账户上训练，报告完成账户条件命中率与初始人口命中率。
10. 模型外比例保护按旧账户与预览新增账户加权后的累计值计算，不能只观察新增批次。冻结保护使用 PCFG 的十万次实际尝试前缀。终态 F 与 A1 的百万次实际 PCFG、作者版 OMEN 前缀另列；重复尝试计费。
11. 参数选择、动态确认和推荐选择均有明确失败记录。模型超时或攻击缺失会显示缺失状态，不作为命中率为零。推荐通过验证阶段封存，终测不能重新选冠军。

## 核验与解释

单元核验覆盖角色互斥、配对偏好、结构编码、保持与刷新、训练重加权不引入目标字符串、待处理分母、模型未知不通过强度门槛、独立确认失败不重选，以及新增成本的配对计算。端到端小规模实验核验校准—封存—验证—封存—终测、实际攻击前缀、缓存和续跑。

正式结论须等待全量记录。即使碰撞率下降，也不能据此推断百万次攻击命中率下降；若没有可行方法、联合优势没有复现，或攻击模型覆盖不足，都应作为结果报告。
