## 预算口径

PCFG/OMEN各100万次，PassLLM各模型执行100万次原始抽样，联合最多300万次；部分PassLLM抽样在长度上限内未形成可保留字符串，保留数略少于100万。保留字符串数与原始抽样数均已提供。中间预算的保留前缀曲线不是精确原始抽样预算曲线；本汇总主要使用百万端点。状态`incomplete`指未达到100万条保留字符串，不能隐藏或改称100万条有效输出。

## 复现与来源

算法快照基于Git提交`b03ce87310ffbb1c56b4c2a169dfe06377172e80`。`manifest.json`是准备阶段记录，其中not_started及资源缺项是当时状态；最终完成范围以本README和results为准。`existing_config.json`关闭终态A仅用于解耦策略导出，独立A在后续任务中实际运行，详见metrics。

`execution_sources`保存实际运行驱动和PCFG兼容处理，包含本机绝对路径与工作目录约定，属于执行记录，不能声称下载后无需配置即可运行。重新执行前需按实际目录修改数据、模型、输出路径，恢复原始源码快照并准备授权语料及依赖。MPS采用float32、SDPA、有效批次64及梯度累积；仅对监督位置投影词表，首批损失与原实现进行过一致性检查，非全运行逐位等价证明。

PCFG仅在Limit reached、返回码-6、已知stdin退出异常及完整百万前缀计数同时满足时接受观测输出，其他失败不降级为零风险。

原始口令、目标/参考口令频次映射、猜测文件、私有分区和模型权重不在公开目录内；本地仍保留。指标文件中的训练摘要用于核验来源，不提供口令内容。evidence_hashes.json记录本地原始证据文件的摘要；package_sha256.json记录此次公开包文件摘要。
