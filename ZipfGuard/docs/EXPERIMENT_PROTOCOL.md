## 主比较

事先指定，不按测试结果改：

1. 不修改。
2. `paper_compatible` HTPG（`d_head <= d_tail`，Length 只加长）。
3. 固定长度与 LSD 对照（原 `no_igr` 键，角色名 `fixed_length_and_lsd_control`）。
4. 验证集上的单项预算选择。
5. `validation-risk-under-modification-cap-v1`：修改率不超过事先档位时，选验证风险最低的至多两项特征。
6. 头部触发的长度响应。它不是完整的“长度加黑名单”政策。

拟议成本档位是修改用户比例 5%、10%、20%。达不到就记不可达。档位在验证集上使用，测试集只报告实际修改率。

## 响应与统计

主实验采用率 1.0。0.5 和 0.2 是敏感性，不是用户研究。确定性与多样化长度响应分开报告。

封闭频次和封闭 n-gram 可以另报最坏值。开放生成不与封闭排序合成一个最大值。命中率分母是受评用户。绝对差用百分点。相对变化另字段存放。

一个种子的封闭比较若因修改漏收而不可发布，整组完整均值也不发布。有效子集只放诊断字段。
