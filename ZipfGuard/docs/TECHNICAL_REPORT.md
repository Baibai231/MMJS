# ZipfGuard 技术报告

## 问题与威胁模型

常见口令集中在分布头部。HTPG 用 Zipf 曲率划出头部，再用信息增益比决定先改哪个特征。信息增益比高，只说明这个特征把头尾标签分得开，不自动等于在给定猜测预算下更难被猜中。

本报告里的预算是离线猜测次数。预算 40 不是 40 次登录。攻击者知道策略模板。冻结攻击沿用修改前的训练集；自适应攻击在修改后的训练集上重拟合。分母是测试用户，除非字段另写“不同口令”。细节见 [威胁模型](THREAT_MODEL.md)。

## 论文基线

带频次 RockYou 的前 1,171 名频数和是 3,899,108，与论文表 III 一致。频数大于 3 的对数回归给出 α=0.914（三位小数）。曲率峰约在 1,172.16，HeadSet 用 `floor`，得到 1,172，没有改写成论文的 1,171。本地总频数 32,603,388，与论文 32,510,281 相差 93,107。空口令和非 UTF-8 的质量解释不了这个差，所以标成未解差异。

九个特征、等权为主的 IGR、以及只对头部口令输出的建议可以单独运行。词表是 VADER 与美国人口普查姓氏的替代表，不是论文作者的原表。多轮实验在合成用户上模拟“半数不改、其余最多采用两项建议”。人数不变，拒绝的用户不会被删掉。这不是实测采用率。论文的 69%、25%、80.23% 来自原文的不同实验，不写入下表的成果栏。

## 新方法与主实验

新方法仍从论文特征里选建议。它在验证集上比较执行某一特征前后的自适应 `cracked@B`，减去修改率权重，最多保留两项得分为正的特征。测试集不参与选择。全体测试用户的绝对百分点差和头部用户的绝对百分点差分成两个字段；相对变化另外存放，不和百分点差写成同一个数。头部指原口令落在训练集曲率头部里的测试用户。

五条臂使用同一支持集（652）、同一公开候选（10,433，按哈希排序）、同一预算。封闭排序的最坏攻击者只在训练集频次和字符 n-gram 之间选取。固定阶马尔可夫按原始生成序号另算一条开放百分点差，不和封闭排序取最大值后再写成一个 `cracked@B`。马尔可夫不是 OMEN。576 项语法的高预算演示仍会饱和，只作历史对照。

下面这组是建议方向、unique 权重和两次改写都留在候选集里之后的结果，文件是 `reports/directed_size900.json`。900 用户、五个种子、离线预算 40。改写掉出候选集的比例是 0。全体测试用户的封闭排序绝对下降：

| 场景 | 长度加黑名单 | 论文 IGR（unique） | 预算/成本 |
| --- | ---: | ---: | ---: |
| Zipf | 7.6 | 0.0 | 0.0 |
| 长尾 | 16.1 | 0.0 | 0.0 |

单位是百分点。论文臂和预算/成本臂五个种子都不高于 0。此前长尾上约 17.9 个百分点的下降，对应的是大约 19% 的测试口令掉出了封闭候选集；候选补全后，这份下降消失。不能把它写成新方法的安全收益。长度加黑名单的下降还在，而且没有掉出候选集。

`reports/directed_size900.json` 属于协议 `robustness-v2`，写于执行器修正和响应因子拆开之前。LSD、非首字母大写和内部日期当时都可能被误判为成功，长度加黑名单用五种后缀，定向长度用固定 `x`。那张表不能当成当前 `robustness-v3` 的结果，也不能把其中的差距单独解释成策略优势。

## 执行状态与响应因子

实验性建议规则是距离严格小于尾部才输出建议。论文写法把 `d_head <= d_tail` 算作更靠近头部。合成对照的头部拟合阈值是频次大于 0；论文全量拟合是频次大于 3。类别距离是众数上的 0/1，词表是替代表。这些都不是完整论文数值复现。

同一特征提取器检查改写结果，状态只有四类：成功、已满足、无法执行、发生冲突。无法执行和冲突都不改口令，也不删除用户。已满足不算新的成功采用。后一步若拆掉前一步已经达到的目标，记为冲突并退回那一步。

长度填充是独立的响应因子，不是某条策略私有的。确定性模式补 `x`，多样化模式先加五种后缀之一，不够再补 `x`。现代黑名单、NIST 长度和定向长度建议共用这个函数、同一采用率假设和同一随机种子约定。黑名单是否触发仍由该策略自己决定。采用率是预先设定的假设，不是用户实验。历史类别混合和 `no_igr` 无方向改写不在这组共享响应里。

## 消融、成本与迁移

下面这段消融是建议方向修正之前的单种子记录，只能说明当时的开关，不能和 `directed_size900.json` 混读。数字在 `reports/ablation_closed_open.json`。

没有用户研究。乐观、中性、保守采用率事先定为 1、0.5、0.2。在 Zipf、300 用户、种子 1 上，乐观采用的绝对下降约 3.3 个百分点；中性和保守在这次随机接受下是 0。这不是记忆实验，也不是 80.23%。

MAYA 的 hak5、faithwriters、phpbb、libero、taobao 都能做频数大于 3 的 Zipf 拟合，α 约 0.49 到 0.80，切分从 6 到 231，都不是 RockYou 的 0.914 和 1,172。等权 IGR 与 RockYou 排序的 Spearman 从约 -0.32 到 0.57。这是分布和排序迁移，不是跨站猜测实验。

## 局限与数据伦理

原始口令留在 gitignore 的本地目录。报告、图和 `summary()` 的默认输出不含猜测字符串。合成演示只有在调用方明确打开时才显示语法字符串，并标明不是泄露口令。

不能声称真实跨站防御、真实可记忆性，或已经复现论文的六数据集攻击数字。PassLLM 未参与。
